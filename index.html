Privacy Policy for Viewport Capture

Last updated: November 1, 2026

Viewport Capture is a Chrome extension that captures the currently active webpage as a sequence of viewport-sized screenshots and downloads them locally as a ZIP archive.

Data Access

Viewport Capture accesses the currently active webpage only when the user explicitly starts a capture using the extension's Capture command.

The extension may temporarily access webpage content that is visible in the browser in order to scroll the page, wait for visible content to render, and create screenshots.

Data Processing

Screenshots and webpage content are processed locally within the user's browser.

Captured screenshots are packaged into a ZIP archive and downloaded directly to the user's device.

Data Collection and Transmission

Viewport Capture does not:

  • Send captured screenshots to an external server.
  • Send webpage content to an external server.
  • Collect browsing history.
  • Collect personal information.
  • Collect authentication information.
  • Collect location information.
  • Use analytics or tracking services.
  • Use advertising services.
  • Sell, share, or transfer user data to third parties.

Temporary Data

Temporary data may be used during an active capture session only as necessary to create screenshots and generate the ZIP archive.

This temporary data is not retained for analytics, tracking, advertising, profiling, or any unrelated purpose.

Remote Code

Viewport Capture does not execute remotely hosted code. The extension's executable code is included in the extension package distributed through the Chrome Web Store.

Third Parties

Viewport Capture does not provide captured webpage content, screenshots, or user data to third parties.

Changes to This Privacy Policy

This Privacy Policy may be updated if the functionality or data practices of Viewport Capture change. Any updates will be published on this page.

Contact

For questions about this Privacy Policy or Viewport Capture, please use the developer contact information provided on the Chrome Web Store listing.
